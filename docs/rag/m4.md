# M4 — Contexto, fontes nativas, resposta com evidências e abstenção

Cobre RAG-06 (modo Sempre consultar), RAG-07 (fontes/citações) e RAG-08
(abstenção). Modo Via ferramentas e UI ficam para M5.

## O que entrega

- `ConversationKnowledge` (migration 0010): bases + modo por conversa;
  API `GET/PUT /api/rag/conversations/<uuid>/sources` com 409 se run ativa
  e filtragem de uuids alheios.
- `answer.prepare`: recuperação prévia autorizada, sem Anthropic; motivos
  `empty | processing | no_evidence | technical`.
- Orçamento RAG ~3000 tokens Claude (≈12000 chars, aproximação registrada;
  tokens E5 ≠ Claude; contagem exata global segue em `context_builder`).
- Blocos nativos `search_result` (`source=kb://…`) + pergunta uma vez;
  `RAG_SYSTEM_ADDENDUM` (só fontes, lacunas, conflitos, sem página inventada).
- `verify_citations` contra o manifesto: índice do provedor ou trecho ≥12
  chars com casamento único; forjada/ambígua/curta = inválida, nunca link.
- `Citation` + `SourceDependency` persistidas; evento `sources` no SSE.
- Hook em `execute_run` (textual); caminho com tools recebe os mesmos
  blocos, com citações verificadas em M5.

## Calibração de abstenção (achado)

similaridade melhor por pergunta (corpus §18, híbrida):

- respondíveis: 0,80–0,92 · sem resposta: 0,79–0,85 → **sobreposição total**.
- Nenhum limiar separa sem arbitrar (§7 veda limiar universal arbitrário).

Decisão: abstenção automática só em sinais estruturais (sem bases, vazia,
indexando, técnica, zero candidatos, `no_terms`); com candidatos, o modelo
adjudica sob instrução estrita e o diagnóstico registra `best_sim` +
`lexical_support` para o inspetor (M5).
