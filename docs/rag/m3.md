# M3 — Busca híbrida, diagnóstico e avaliação (RAG-05, §8, §18)

## O que entrega

- `RetrievalService` único (`chat/services/rag/retrieval.py`): elegibilidade
  (owner → bases → versão ativa → perfil) antes de qualquer candidato, nos
  dois pilares; 30/pilar; RRF k=60 pesos iguais, desempate por id; até 6
  finais com dedup Jaccard ≥0,8; sem scores como probabilidade.
- Métodos `hybrid | lexical | vector`, sempre rotulados no diagnóstico.
- `followup.py`: pergunta atual + até 20 palavras do último tópico quando a
  pergunta tem ≤8 palavras; original/efetiva separadas.
- Persistência `RetrievalRun` + `Evidence` (migration 0009) com `kb://` ids.
- Avaliação: corpus versionado (8 docs PT/EN), 40 perguntas balanceadas,
  comando `rag_eval`, relatório `docs/rag/eval_report.md`.

## Resultados (§18)

Meta Hit@6 ≥ 0,85 atingida. Híbrida não supera o baseline vetorial neste
corpus pequeno (AND lexical × chunks curtos) — registrado, sem ajuste de
gabarito. 8/8 sem-resposta retornam candidatos: M4 deve abster-se.
