# M5 — Tools no loop, streaming de citações e UI completa

Cobre RAG-06 (modo Via ferramentas), RAG-07 (citations_delta) e a UI de
Conhecimento/Fontes (§13). Revogação e retenção ficam para M6.

## O que entrega

- Tools locais `search_knowledge_base(query)` + `read_knowledge_excerpt(id)`
  (`chat/services/rag/tools.py`): contexto via `ExecutionContext` (usuário,
  conversa, bases selecionadas); excerpt só de evidência da mesma execução.
  Registradas no catálogo → `available` 4 → 6 por conversa.
- Servidor nunca inventa tool call: modo Sempre consultar usa o serviço
  direto; modo Via ferramentas expõe as tools ao Claude no loop existente.
- `_iter_stream_text` (`generation.py`): fakes/`text_stream` preservam gating;
  stream real do SDK itera eventos brutos (`text_delta` + `citations_delta`),
  reconciliados com `get_final_message`. Sem WebSocket paralelo.
- UI: página `/knowledge/` (bases, upload, estados, excluir com confirmação),
  popover Fontes por conversa (seleção + modo, 409 com run ativa), chips
  `[n] doc` por mensagem, diálogo de fonte autenticado, selo distinto
  "Fontes disponíveis" × "Fontes consultadas".
- Sem bases selecionadas, o chat segue o comportamento anterior; aviso de
  que desativar buscas não limpa o histórico + oferta de nova conversa.
