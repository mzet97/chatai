# ADR-005 — Sem resumo automático por IA na v1

Data: 2026-09-14 · Estado: aceita.

Contexto: RF-09 exige redução determinística por remoção de turnos completos.
Decisão: sem sumarização; interface indica turnos omitidos + modo estrito.
Alternativas descartadas: resumo automático (custo extra, perda de informação,
complexidade). Fica como extensão futura no backlog.
